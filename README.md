# Student Marks Searching and Sorting

## Introduction
This project demonstrates searching and sorting operations using Python.

## Objectives
- To search student marks using Linear Search.
- To sort student marks using Bubble Sort.
- To understand basic data structure operations.

## Data Structure
Python List is used to store student marks.

## Algorithms Used
1. **Linear Search:** Searches for a given mark in the list.
2. **Bubble Sort:** Arranges marks in ascending order.

## Technologies Used
- Python
- Visual Studio Code
- GitHub

## Conclusion
This project helps understand searching and sorting algorithms using a simple Python program.
