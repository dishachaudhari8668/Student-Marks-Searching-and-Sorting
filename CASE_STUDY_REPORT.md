# Case Study: Student Marks Searching and Sorting

## 1. Introduction
Searching and sorting are important operations in Data Structures. This project uses Python to search and sort student marks.

## 2. Objectives
- To implement Linear Search.
- To implement Bubble Sort.
- To arrange marks in ascending order.

## 3. Data Structure Used
A Python list is used to store student marks.

## 4. Algorithms Used

**Linear Search:** It checks each element one by one to find the required marks.

**Bubble Sort:** It compares adjacent elements and swaps them if they are in the wrong order.

## 5. Input
Marks: 45, 20, 80, 35, 60

## 6. Output
- Search Result: Marks found at position 4 (when searching for 35).
- Sorted Marks: 20, 35, 45, 60, 80

## 7. Conclusion
This project demonstrates Linear Search and Bubble Sort using Python. It helps understand basic searching and sorting operations.
